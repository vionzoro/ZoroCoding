# 可选集成设计修订

本修订收窄 `2026-07-28-zorocoding-macos-design.md` 第 29–38 行的非目标限制：允许用户自行配置一个 MCP 记忆服务或一个 approval-review/v0 HTTP endpoint。插件市场、通用 MCP 管理中心、云端同步、自动定时任务和远程发布仍不在范围内。

## 授权与默认行为

- 所有集成默认关闭，服务地址为空，记忆读取与写入分别默认关闭。
- 全局启用与逐项目授权必须同时满足；新项目不会继承授权。撤销项目勾选或关闭集成后，后续运行时请求必须停止。
- 操作审查可选择手动确认或 HTTP 审查服务。服务不可用时只能阻止操作或请求手动确认；默认阻止操作。没有自动允许策略。
- 集成不能扩大项目文件访问或命令权限，不能替代现有用户批准流程。

## 设置与凭证

设置页使用已有集成配置 IPC，保存启用状态、服务地址、读写开关、项目标识列表、审查方式和不可用策略。数据库迁移增加 `options_json` 列，旧配置的新增权限默认关闭；未传入选项时保留原值。

令牌是只写输入，使用密码框且没有显示按钮。读取 IPC 只返回凭证存在状态所需的末四位信息，界面只显示“已保存”，不显示末四位。留空保留原令牌，显式勾选才清除；保存成功或存储不可用时清空输入。令牌通过现有加密存储保存，不写入配置 JSON、日志、预览或错误文本。

地址遵循已有安全校验：远程服务使用 HTTPS，本机回环地址可使用 HTTP；拒绝嵌入账号、查询参数及 URL 片段。错误使用固定中文文案，避免回显服务响应里的敏感内容。

## 数据发送与预览

页面用直白文案说明：外部服务会收到发送的内容。授权是必要条件，不意味着可以上传全部项目或对话。

| 用途 | 未来允许发送的最小范围 |
| --- | --- |
| 记忆读取 | 检索关键词和必要任务摘要；返回相关记忆 |
| 记忆写入 | 用户确认的任务摘要和经验记录 |
| 操作审查 | 待执行操作、命令或补丁及必要任务摘要 |

不默认发送完整对话、文件、环境变量或项目绝对路径。令牌只用于鉴权，不进入请求正文。未来传输实现须在发送前展示并确认经过裁剪的具体请求内容，并在主进程执行全局开关、项目授权、读写开关与权限检查。

本次设置页面的“查看将发送的内容”是本地配置与数据类别预览，明确标记为当前表单而非真实请求，不读取项目文件、不连接外部服务。“测试连接”保留为禁用控件，并明确提示尚未接入。保存配置不证明服务可连接，也不启动记忆或审查请求。传输与实际请求预览由后续运行时改动实现。

## 界面与验证

新增界面沿用严格黑绿主题：纯黑背景、荧光绿文字与边框，不新增颜色、透明度或阴影。提供独立的项目复选框、读写开关、审查方式与不可用策略选择。

验证覆盖：密码输入、保存后清空、不回显凭证、预览不含凭证与项目路径、默认关闭、逐项目选择和撤销、选项持久化、存储不可用时禁用，以及使用模拟模型服务的端到端设置与普通任务流程。设置与预览本身不得产生网络请求。
