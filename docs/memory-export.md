# 记忆导出

默认关闭。只有设置 `ZORO_MEMORY_EXPORT_URL` 为接收端的 HTTPS 写入地址，完成任务的工作区才显示导出预览。地址不能包含用户信息、查询参数或片段；不会跟随重定向。

1. 选择目标并预览。候选仅包含完成/跳过步骤数、文件修改记录数，以及不含路径的记录标识。任务标题、提示词、对话、步骤文本、文件名、文件内容、补丁和原始工具输出均不进入候选。
2. 对此目标单独同意，将当前预览保存到本地待发送队列。预览和任务完成本身都不会发送请求。
3. 发送当前任务的已同意记录；发送开始前可撤回同意。下次启动会发送仍已同意且目标仍配置的待发送记录，因此离开应用前请撤回不想发送的记录。

HTTP 请求为 `POST`，JSON 格式如下；`entry` 复用记忆记录类型：

```json
{
  "client_write_id": "unique-write-reference",
  "entry": {
    "id": "opaque-outcome-reference",
    "title": "任务完成记录",
    "content": "任务已完成。完成步骤：1；跳过步骤：0；文件修改记录：1。"
  }
}
```

接收端应按 `client_write_id` 去重，并返回成功状态及 JSON：

```json
{ "client_write_id": "unique-write-reference", "id": "receipt-reference" }
```

只有匹配的写入标识和非空接收记录标识才能确认接收。发送前持久化为 `sent`；成功确认为 `acked`。超时、无效确认或发送中断为 `unknown`，不会自动重试，以免重复写入；中断后仍为 `sent` 的记录在重启时转为 `unknown`。导出状态与任务完成状态独立。

目标地址变化需要新的预览和同意；旧目标的待发送记录保留，可撤回。队列最多容纳 100 条未确认记录，包括接收状态未知的记录；不会自动丢弃它们。没有自动导出、远端更新/删除同步或未知记录重试功能。
